SilosMC - Local-first Minecraft server manager for Windows, macOS & Linux.

Run Paper, Fabric, Forge, NeoForge, Vanilla, Bedrock (BDS) and PocketMine-MP servers on your own PC with zero port forwarding. SilosMC auto-provisions Adoptium Java and PHP runtimes, provides a live console, backups, Modrinth/CurseForge content browser, and zero-config Playit.gg tunnels.
